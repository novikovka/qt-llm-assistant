# Qt-ассистент с локальной LLM (llama.cpp + Qt Widgets)

Учебный проект по предмету «Визуальное программирование» (практика 3).

## Цель

Десктопный чат на Qt Widgets, который отвечает локальной языковой моделью через llama.cpp: без облака, без интернета в работе и без видеокарты. Заодно это первый шаг в сторону Applied / Edge AI.

## Сроки задания

| Срок | Что сдаём | Входит в этот README |
|---|---|---|
| до 30 октября | Отчёт: описание нового инструмента и скриншоты программы | да |

## Требования

### Функциональные

- F1. Пользователь вводит вопрос и отправляет его кнопкой или клавишей Enter.
- F2. Ответ локальной модели показывается в окне чата.
- F3. Ответ выводится потоком, по мере генерации.
- F4. Если сервер модели недоступен, показывается понятное сообщение об ошибке.
- F5. Кнопка «Стоп» прерывает генерацию.

### Нефункциональные

- Работает офлайн на процессоре (GPU не нужен).
- Debian 13, Qt 6, C++17, сборка через CMake.
- Окно не зависает во время генерации (сетевые запросы асинхронные).
- Код разделён на слои: интерфейс отдельно, клиент модели (`LlmClient`) отдельно.

### Вне рамок этого проекта

RAG, QML, сохранение истории чатов, линковка библиотеки llama.cpp, работа на GPU.

## Стек (варианты от самого простого)

1. **llama.cpp как отдельный процесс `llama-server` + HTTP-запросы из Qt (выбрано).** Минимум риска к дедлайну.
2. Линковка библиотеки llama.cpp прямо в приложение. Сложнее, оставляем на потом.
3. Ollama. Не берём: он скрывает как раз то, что нужно изучить.

Остальное:
- Qt Widgets: `QWidget`, `QPlainTextEdit`, `QLineEdit`, `QPushButton`.
- Сеть и данные: `QNetworkAccessManager`, `QJsonDocument`.
- Модель: Qwen Instruct 1.5–3B в формате GGUF с квантизацией Q4_K_M (размер уточним по объёму ОЗУ).

## Этапы

| № | Этап | Срок | Результат и проверка |
|---|---|---|---|
| 1 | Сборка llama.cpp и запуск модели из терминала | 21.10 | Модель отвечает в консоли, записан замер скорости (токенов/с) и объём ОЗУ. Скриншоты сохранены |
| 2 | Запуск `llama-server` и проверка запросом `curl` | 22.10 | Сервер принимает запрос и возвращает ответ, скриншот |
| 3 | Qt Widgets: окно чата, запрос и ответ целиком | 25.10 | Окно отправляет вопрос серверу и показывает полный ответ (F1, F2) |
| 4 | Потоковый вывод, кнопка «Стоп», обработка ошибок | 28.10 | Ответ появляется по частям, «Стоп» работает, при остановленном сервере видно сообщение (F3–F5) |
| 5 | Отчёт | 30.10 | Описание llama.cpp, GGUF и квантизации, скриншоты, таблица замеров |

После каждого этапа: коммит в GitHub с понятным сообщением.

## Правила работы с AI-агентом

1. Перед каждым этапом агент пишет план без кода, я подтверждаю.
2. Предлагаются варианты от самого простого.
3. Шаги мелкие и проверяемые: собрал, запустил, проверил.
4. Меняется только то, что я попросила.
5. Коммит по этапам.
6. Агент объясняет каждый фрагмент кода.

## Риски

- **Слабый процессор или мало ОЗУ.** Берём модель поменьше или квантизацию агрессивнее.
- **Маленькие модели хуже отвечают по-русски.** В тестах 5 русских вопросов, при плохом качестве пробуем другую модель.
- **Разбор потока ответов сложнее обычного запроса.** Поэтому сначала этап 3 без потока, потом этап 4.
